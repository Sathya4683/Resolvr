## Symptoms
- Speed test shows much lower speed than the plan.
- Pages load slowly and downloads take long.

## Likely causes
- Testing over WiFi far from the router, or on an old phone that cannot reach plan speeds.
- Many devices downloading or streaming at the same time.
- Background updates (Windows, game consoles, cloud backups).
- Router 2.4 GHz band in use (max practical speed around 40-60 Mbps).

## Steps
1. Ask the customer to stop downloads on other devices.
2. Run a speed test on a laptop connected with a LAN cable directly to the router, using the company speed test page.
3. If wired speed is within 80% of the plan, explain that WiFi speed depends on distance, walls and device capability. Recommend the 5 GHz band and placing the router centrally.
4. If wired speed is below 80% of the plan, check the plan's FUP status (see KB-005) and the line profile in CRM.
5. If FUP is not exhausted and the line profile is correct, restart the router and run the test again.
6. If speed is still low, raise a **speed complaint** ticket for the network team with the test screenshots.

## Escalate when
- Wired speed stays below 50% of the plan after a restart.
- The issue repeats for more than 3 days.
