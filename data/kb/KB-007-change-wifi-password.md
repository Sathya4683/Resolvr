## Symptoms
- Customer forgot the WiFi password or wants to change it.
- Customer suspects neighbours are using their WiFi.

## Likely causes
- Default password printed on the router was never changed.
- Password shared widely with guests.

## Steps
1. Easiest option: ask the customer to open the **MyNet app > Router > WiFi settings** and change the name and password there. Changes apply within a minute.
2. Alternative: connect to the router, open `192.168.1.1` in a browser and log in with the admin credentials printed on the router label.
3. Go to **WLAN / Wireless settings**, change the SSID and the WPA2/WPA3 password (at least 8 characters, mix of letters and numbers).
4. Save and reconnect all devices with the new password.
5. Advise the customer to change the router admin password as well.
6. Never ask for or note the new password in the ticket.

## Escalate when
- The router admin page does not open and the app shows the router as offline (treat as a connectivity issue, see KB-001).
