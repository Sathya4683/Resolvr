## Symptoms
- Mobile data is very slow, videos buffer, apps take long to load.
- Phone shows 4G/5G but speed is under 1 Mbps.

## Likely causes
- Daily high-speed quota used up (speed reduced to 64 kbps).
- Network mode set to 3G/2G only.
- Congestion at a busy location (malls, stations, events).

## Steps
1. Check if the daily high-speed data is exhausted. If yes, explain the reduced speed and offer a booster pack.
2. Set the preferred network type to **5G/4G auto**.
3. Run a speed test at two different locations to see whether it is location-specific.
4. For 5G phones, make sure the phone software is updated and 5G is enabled in settings.
5. If slow only at one location at certain hours, log **network feedback** with the location.

## Escalate when
- Speed stays below 1 Mbps everywhere for more than 24 hours with quota available.
